#ИНФОРМАТИКА
Перебор последовательностей чисел

## Пример

### Задание
Откройте файл электронной таблицы, содержащей в каждой строке три натуральных числа.

[Задание 9](https://inf-ege.sdamgia.ru/get_file?id=225709)

Выясните, какое количество троек чисел может являться сторонами треугольника, то есть удовлетворяет неравенству треугольника. В ответе запишите только число.

### Файл
Я буду показывать работу на python, но можно решать прям в табличном редакторе. Если ваш файл имеет формат `.ods`, `.xlsx`, `.xls` и т.п, то в моём случае его надо перевести в `.csv`. Почти в любом табличном редакторе можно выбрать `Файл -> Сохранить как -> Выбрать формат файла .csv`. Почему именно он? Этот формат текстовый, то есть его можно буквально открыть в блокноте и получить все значения, для нас это удобно потому, что для его обработки не понадобиться сторонних библиотек.

### Решение
1. Для начала нам нужно будет перебрать все строки и превратить их в массив чисел (используемые инструменты: [map](Функции.md#MAP), [генераторы](Python%20фишки.md#Генераторы))
	```python
	for line in open("9.csv"): # В line будут все строки из нашего файла 9.csv
		nums = sorted(list(map(int, line.strip().split(",")))) 
		"""
		- sorted - сортируем сисок, чтобы его легче было обрабатывать 
		- list - создает массив из map
		- map - каждое значение переделывает в значение int
		- strip() - убирает лишние пробелы с начала или с конца
		- split() - разделяет строку по нужному симолу, если у вас не работает разделение, то выведите линию и посмотрите, какой в нем стоит разделительный знак
		"""
	```

2. По условию нам надо получить **количество троек чисел может являться сторонами треугольника**, для этого создадим переменную для хранения кол-ва необходимых чисел *(счётчик)*.
	```python
	c = 0 # Наш счётчик
	
	for ...:
		nums = ...
		
		c += ... # Наше будущее условие
		
	print(c) # Вывод итогового ответа 
	```

   *Про то почему мы используем конструкцию `c += условие` уже где-то рассказывал, но повторюсь. Python не типизированный язык программирования и строго указанных типов у него фактически нет. Поэтому некоторые все таки какие никакие типы могут без особого труда поменять свой тип на другой и не случайно, а в зависимости от их содержимого. В нашем случае `bool` значения в типе `int` преобразует `True` в 1, а `False` в 0, эту вещь мы используем для счётчика добавляя 1 если условие верно и 0 если нет*

3. По условию является сторонами треугольника, для этого в сумме две самые мелкие стороны должны быть больше самой большой.
	```python
	for ...:
		nums = ...
			
		c += nums[0] + nums[1] > nums[-1] # из-за sorted, все числа в массивен стоят в порядке возрастания 
	```

В итоге при запуске получаем - `2453`! Верно!

### Код

```python
c = 0 # Счётчик

for line in open("9.csv"): # Перебор всех линий в файле
    nums = sorted(list(map(int, line.strip().split(",")))) # Создание сортированного в порядке возрастания массива из числе в строке
    
    c += nums[0] + nums[1] > nums[-1] # Условие

print(c) # Вывод кол-ва строк, которые подходят условию. 2453!
```
