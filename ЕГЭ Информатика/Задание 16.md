## Тип 1 (Значение выражения, полное условие)

### Задание
Алгоритм вычисления значения функции _F_(_n_), где _n_  — натуральное число, задан следующими соотношениями:

`F(n)  =  n при n > 2024;`
`F(n)  =  n · F(n + 1), если n ≤ 2024.`

Чему равно значение выражения `F(2022) / F(2024)`?

### Решение
1. Создаём рекурсивную функцию. Создаём условие выхода и продолжения рекурсии.
   ```python
     def f(n): # Функция
		 if n > 2024: return n # При n больше 2024 значение функции будет равно n 
      
		 return n * f(n + 1) # В ином случае n * f(n + 1)
   ```
  2. Выводим необходимое значение
     ```python
     def f(n):
         ...
         
     print(f(2022) / f(2024))
     ```

Получаем ответ `4090506`!

### Полный код
```python
def f(n): # Функция
    if n > 2024: return n # При n больше 2024 значение функции будет равно n 
    
    return n * f(n + 1) # В ином случае n * f(n + 1)

print(f(2022) / f(2024)) # Выводим значение
```

## Тип 2 (Значение выражения, неполное условие)

### Задание
Алгоритм вычисления значения функции F(_n_), где _n_  — натуральное число, задан следующими соотношениями:

`F(1)  =  1;`
`F(2)  =  1;`
`F(n)  =  F(n – 2) · n при n > 2.`

Чему равно значение функции `F(7)`? _В ответе запишите только натуральное число._

### Решение
1. У нас есть условие `F(1)  =  1; F(2)  =  1;`, которое выполняется при `n <= 2`. Из данного условия понимаем что при `n <= 2` функция равна `1`. Так создаем рекурсивную функцию.
   ```python
   def f(n):
       if n <= 2: return 1 # При n <= 2 функция равна 1
       
       return f(n - 2) * n # При n > 2 результат функции будет f(n - 2) * n
   ```
   2. Выводим результат функции с аргументом 7
     ```python
     def f(n):
        ...
        
     print(f(7))
     ```

Получаем ответ `105`!
### Полный код
```python
def f(n): # Функция
    if n <= 2: return 1 # При n <= 2 функция равна 1
    
    return f(n - 2) * n # При n > 2 результат функции будет f(n - 2) * n

print(f(7)) # Выводим результат функции f(7)
```


## Трудности

### Закончилась подписка на рекурсию
Если в python вам начинает выводить ошибку о запрете продолжения рекурсии
```trace
RecursionError: maximum recursion depth exceeded while calling a Python object
```
 то проверьте условие, есть вероятность что у вас что-то сделано неправильно. Если ошибок нет, то необходимо увеличить лимит рекурсий:
 ```python
 import sys # Библиотека для работы с системой
 
 sys.setrecursionlimit(100000) # Аргументом является лимит на рекурсии
 ```

Единственное что наслышан о том, что в `PyCharm` такое не прокатит из-за ограничений оболочки. 

### "В последовательности"
Если в условие к задачке написано `найдите десятое число в последовательности`, то положение будет эквивалентно аргументу функции.
