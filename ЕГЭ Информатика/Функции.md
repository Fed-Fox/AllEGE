# MAP
Функция перебирает каждое значение из массива и применяет на него функцию

#### Синтаксис
`map(function, iterable)` возвращает map, который имеет возможность делать так:
```python
n1, n2 = map(...)
```

#### Использование
Можно использовать для преобразования массива вместо использования генераторов

# ZIP
Функция объединяет два массива в один или наоборот.

#### Синтаксис
`zip(iterable, iterable, strict=False)` объединяет два массива в один [map](Функции.md#MAP). Аргумент strict выкидывает ошибку при разной длине массивов *(по стандарту берётся длинна самого короткого)*
`zip(*iterable)` разъединяет уже собранный список [map](Функции.md#MAP) в два списка возвращая [map](Функции.md#MAP).

#### Использование
Обычно используется для создания пар элементов.

# ANY
Функция позволяет определить есть ли в массиве хотя бы 1 значение True.

#### Синтаксис
`any(iterable)` возвращает boolean значение, которое выдает True, если хотя бы одно значение True. 

#### Использование
Используется с [генераторами](Python%20фишки.md#Генераторы) для проверки значений массивов.

---

# ALL
Функция позволяет определить что все значения в массиве True.

#### Синтаксис
`all(iterable)` возвращает boolean значение, которое выдает True, если все значения в массиве True. 

#### Использование
Используется с [генераторами](Python%20фишки.md#Генераторы) для проверки значений массивов.
