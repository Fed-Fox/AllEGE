#ИНФОРМАТИКА
Сколько весит фотка мамы Нолана?

## Тип 1 (Изображения и их передача)
В данном задании размер изображения считается по формуле:
$$M = w * h * i * s\text{ (бит)}$$
где *M - размер изображения в битах*; *w - ширина изображения*; *h - высота изображения*; *i - размер одного пикселя в битах*; *s - сжатие изображения (от 0 до 1)*

Для определения размера одного пикселя есть формула:
$$i = log_2N\text{ (бит)}$$
где *i - размер одного пикселя в битах*; *N - кол-во цветов в палитре или просто палитра*

В заданиях с передачей изображений есть понятие пропускная способность. Это то сколько памяти сеть может передать в секунду.
$$b = \frac{M}{t}\text{ (бит/сек)}$$
где *b - пропускная способность*; *M - размер изображения*; *t - время, за которое передался файл изображения*

### Задание
Камера наблюдения снимает видео с частотой _n_ кадров в секунду (_n_  — целое число) и передаёт его по каналу с пропускной способностью 750 Кбайт/⁠сек. Видео снимается с разрешением 1024 × 768 пикселей и палитрой 256 цветов, при этом используются методы сжатия, позволяющие уменьшить размер изображения в среднем на 85%. Определите максимально возможное значение _n_, при котором возможна передача в режиме реального времени.

### Решение
1. Задачка не из лёгких как для понимания, так и для решения. Разберём: чтобы передавать в режиме реального времени, то есть все фотографии, что сделала камера успевали отправиться, нужно чтобы размер всех отправленных фотографий был не больше пропускной способности. 
2. Найдём размер одного изображения
   $$M = 1024 * 768 * log_2256*(1 - 0.85) = 1024 * 768 * 8 * 0.15 = 943718,4бит$$
3. Далее переведём пропускную способность в биты и распишем неравенство
   $$M * n \leq Mb$$
   $$Mb = \frac{b}{t} = 750 Кбайт = 750 * 1024 * 8 бит = 6144000 бит$$
   *(берём t = 1c, потому что нам нужно найти частоту кадров в секунду)*
4. Решаем неравенство
   $$943718,4 * n \leq 6144000$$
   $$n \leq \frac{6144000}{943718,4}$$
   $$n \leq  6,51$$

А раз *n - целое число*, то ответом будет `6`! 

## Тип 2 (Звук и его передача)
В этом задании размер изображения считается по формуле:
$$M = F * V * i * t\text{ (бит)}$$
где *M - размер изображения*; *F - формат (моно - 1, стерео - 2, квадро - 4)*; *V - частота дискретизации*; *i - разрешение*; *t - время в сек*

В заданиях с передачей звука есть понятие пропускная способность или же скоростью передачи. Это то сколько памяти сеть может передать в секунду.
$$b = \frac{M}{t}\text{ (бит)}$$
где *b - пропускная способность*; *M - размер файла*; *t - время, за которое передался файл*

### Задание 
Маша скачивает из Интернета альбом любимой группы, оцифрованный в формате стерео с частотой дискретизации 56 000 Гц и разрешением 15 бит без использования сжатия. В альбоме 28 треков общей длительностью 27 минут 27 секунд. Каждый трек содержит заголовок, это одно и то же целое число Кбайт для всех треков. Каков **минимально** возможный объём заголовка трека в Кбайт, если известно, что время скачивания всего альбома по каналу связи со скоростью передачи данных 367 217 732 бит/с превышает 332 секунды? В ответе запишите только целое число.

### Решение
1. Распишем сколько у нас будет весить один трек:
   $$M = m + h$$
   где *M - размер всего звукового файла*; *m - размер звука*; *h - размер заголовка*
2. Распишем теперь размер всего альбома
   $$M * 28* = (m + h) * 28 = 28m + 28h$$
3. Напишем и решим неравенство
   $$28 * (F * V * i * t) + 28h > b * T$$
   $$28h > b * T - F * V * i * (28 * t)$$
   $$28h = 367217732 * 332 - 2 * 56000 * 15 * 1647$$
   $$h > \frac{119149327024}{28}$$
   $$h > 4255333108 бит$$
   $$h > 519449,8 Кбайт$$ 

Минимальный размер заголовка в Кбайт равен `519450`!
