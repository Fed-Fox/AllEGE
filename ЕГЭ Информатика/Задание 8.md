## Тип 1 (Положение слова)

### Задание
Все четырёхбуквенные слова, составленные из букв Р, Е, К, А, записаны в алфавитном порядке и пронумерованы, начиная с 1. Начало списка выглядит так:

1.  АААА
2.  АААЕ
3.  АААК
4.  АААР
5.  ААЕА
6. ...

Под каким номером в списке идёт первое слово, в котором нет буквы А?

### Решение
1. Создаём алфавит из необходимых слов и сортируем их в алфавитном порядке
	```python
    a = sorted("РЕКА") # sorted отсортирует нашу строку в АЕКР
    ```
2. Далее мы с помощью [product](Python%20фишки.md#Функция%20product) и [enumerate](Функции.md#ENUMERATE) создадим массив со всеми вариациями слов и получим пронумерованный массив.
	```python
	from itertools import * # Импортируем библиотеку
	
	a = ...
	
	for p, v in enumerate(product(a, repeat = 4), start = 1): # product - перебор всех вариантов, repeat - 4-ёх буквенные слова; enumerate - пронумерование всех элементов, start - с 1 начинаем счёт; p - позиция элемента; v - элемент
    ```
3. Проверяем условие, и если оно окажется верным выводим позицию и обрываем цикл
	```python
	a = ...
	
	for p, v in ...:
	    if v.count("А") == 0: # Отсутсвуют буквы А в элементе
	        print(p) # Выводим позицию
	        break # Ломаем цикл, чтобы больше не перебирал массив 
    ```

Получаем в итоге `86`!
### Итоговый код
```python
from itertools import * # Импортируем библиотеку для перебора чисел

a = sorted("РЕКА") # Получаем отсортированный алфавит

for p, v in enumerate(product(a, repeat = 4), start = 1): # product - перебор всех вариантов, repeat - 4-ёх буквенные слова; enumerate - пронумерование всех элементов, start - с 1 начинаем счёт; p - позиция элемента; v - элемент
    if v.count("А") == 0: # Проверяем условие
        print(p) # Выводим позицию
        break # Обрывавем цикл
```

## Тип 2 (Кол-во слов)

### Задание
Сколько слов длины 5, начинающихся с гласной буквы, можно составить из букв Е, Г, Э? Каждая буква может входить в слово несколько раз. Слова не обязательно должны быть осмысленными словами русского языка.

### Решение
1. Создаём алфавит из необходимых слов
	```python
    a = "ЕГЭ"
    ```
2. Далее мы с помощью [product](Python%20фишки.md#Функция%20product) создадим массив со всеми вариациями слов
	```python
	from itertools import * # Импортируем библиотеку
	
	a = ...
	
	for v in product(a, repeat = 5): # product - перебор всех вариантов; repeat - слова длины 5
    ```
3. Создаем счётчик, плюсуем условие и выводим
	```python
	a = ...
	
	c = 0
	
	for v in ...:
	    c += v[0] in "ЕЭ" # Первый символ является одним из строки "ЕЭ" (все гласные)
    
    print(c)
    ```

Получаем в итоге `162`!
### Итоговый код
```python
from itertools import * # Импортируем библиотеку для перебора чисел

a = "ЕГЭ" # Алфавит

c = 0 # Счётчик

for v in product(a, repeat = 5): # Слова из 5-ти букв и алфавита Е, Г, Э
    c += v[0] in "ЕЭ" # Первый символ является одним из строки "ЕЭ" (все гласные)

print(c) # Выводим результат
```

## Тип 3 (Кол-во слов без повторения)

### Задание
Руслан составляет 6-⁠буквенные коды из букв Р, У, С, Л, А, Н. Каждую букву нужно использовать ровно один раз, при этом нельзя ставить рядом две гласные. Сколько различных кодов может составить Руслан?

### Решение
1. Создаём алфавит из необходимых слов
	```python
    a = "РУСЛАН"
    ```
2. Далее мы с помощью [permutations](Python%20фишки.md#Функция%20permutations) создадим массив со всеми вариациями без повторений
	```python
	from itertools import * # Импортируем библиотеку
	
	a = ...
	
	for v in permutations(a, 6): # permutations - перебор всех вариантов без повторений; 6 буквенный код
    ```
3. Создаем счётчик, плюсуем условие (в нем используется [all](Функции.md#ALL) и [генераторы](Python%20фишки.md#Генераторы)) и выводим
	```python
	a = ...
	
	c = 0 # Счётчик
	
	for v in ...:
		v = ''.join(v) # Для работы нашго условия переделаем наш массив v в строку
	    c += all([''.join(p) not in v for p in permutations("УА", 2)]) # for p in permutations("УА", 2) - содержит все пары с гласными (тут приведён многоразовый вариант который удобен с большим кол-вом гласных, чтобы не записывать их вручную); Проврям что всех пар гласных нет в нашем слове; p переводим в строку
    
    print(c) # Выводим
    ```

Получаем в итоге `480`!
### Итоговый код
```python
from itertools import * # Импортируем библиотеку

a = "РУСЛАН" # Алфавит

c = 0 # Счётчик

for v in permutations(a, 6): # permutations - перебор всех вариантов без повторений; 6 буквенный код
    v = ''.join(v) # Для работы нашго условия переделаем наш массив v в строку
    c += all([''.join(p) not in v for p in permutations("УА", 2)]) # for p in permutations("УА", 2) - содержит все пары с гласными (тут приведён многоразовый вариант который удобен с большим кол-вом гласных, чтобы не записывать их вручную); Проврям что всех пар гласных нет в нашем слове; p переводим в строку

print(c) # Выводим
```

## Тип 4 (Кол-во чисел)

### Задание
Сколько существует различных трёхзначных чисел, записанных в четверичной системе счисления, в записи которых сумма первой и последней цифры строго больше цифры стоящей по середине?

### Решение
1. Создадим цикл из трёхзначных чисел в четверичной СС. Для этого будем использовать [product](Python%20фишки.md#Функция%20product) и исключим все числа начинающиеся с 0.
	```python
	from itertools import *
	
	for n in product("0123", repeat = 3): # "0123" - Алфавит четверичной СС; repeat - трёхзначные числа
        if n[0] == "0": continue # Если первое число равно 0, то пропускаем и идём к следующему (010 - нам не подойдет, потому что оно двухзначные)
    ```
2. Создадим счётчик и разобьем все значения в отдельный массив для более удобной обработки (используем [генераторы](Python%20фишки.md#Генераторы))
	```python
	c = 0
	
	for n in ...:
	    if ...: continue
	    
	    nums = [int(x) for x in n]
    ```
3. Проверяем условие и выводим
	```python
	c = ...
	
	for n in ...:
	    if ...: continue
	    
	    nums = ...
	    
	    c += nums[0] + nums[-1] > nums[1]
	
	print(c)
    ```

Получаем в итоге `38`!
### Итоговый код
```python
from itertools import * # Импортируем библиотеку

c = 0 # Счётчик

for n in product("0123", repeat = 3): # "0123" - Алфавит четверичной СС; repeat - трёхзначные числа
    if n[0] == "0": continue # Если первое число равно 0, то пропускаем и идём к следующему (010 - нам не подойдет, потому что оно двухзначные)

    nums = [int(x) for x in n] # Создаём массив разрадов нашего числа n

    c += nums[0] + nums[-1] > nums[1] # Если первое число + последнее число больше среднего, то добавляем счётчик

print(c) # Выводим
```
