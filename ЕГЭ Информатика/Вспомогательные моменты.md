# Переводы СИ
Для перевода из разных систем счисления существует много разных способов и использование каждого зависит от самой системы счисления. Разберу каждый из них от самого простого и малоиспользуемого до самого сложного, которого можно использовать практически со всеми системами счисления.

## Из десятичной в СИ

1. **Для 2, 8, 16:**
   Для таких СИ есть встроенное в python решение, но к сожалению оно ограниченно их количеством. Из доступных есть самые используемые СИ (двоичная, восьмеричная, шестнадцатеричная)
   ```python
	n = 138
		
	print(bin(n)) # 0b10001010
	print(oct(n)) # 0o212
	print(hex(n)) # 0x8a
   ```
   
   Если заметить, то в каждом из выводов есть 2 символа перед числом, которое означают СИ, в которую мы перевели число. Убрать его можно обычном [срезом](Python%20фишки.md#Срезы) строки
   ```python
	n = 138
		
	print(bin(n)[2:]) # 10001010
	print(oct(n)[2:]) # 212
	print(hex(n)[2:]) # 8a
   ```
   
2. **Для 2 - 9:**
   Данный вариант будет схож со следующим, но немного упрощённым. Немного теории: Чтобы перевести из десятичной СИ в любую другую, вкратце делить число на число СИ пока оно не станет равно 0, выписать остатки от деления, а далее развернуть полученную последовательность.
   ![600](perevod_iz_dec_v_si.png)
   В данном примере я перевел число `138` в 5-ичную СИ и в итоге получил `1023`. 

   Примерно таким же образом бы будем это делать функцией.
   ```python
    def f(n, b): # n - десятичное число; b - степень счисления
		s = "" # Строка для хранения результата
    
		while n != 0: # Проводим операцию пока число не "закончится"
			s += str(n%b) # Записываем в результат остаток от деления числа на СИ
			n //= b # Обрезаем обработанное число и записываем обратно
	       
		return s[::-1] # s[::-1] инвертирует строку

	print(f(138, 5)) # 1023
   ```

   Почему же эта функция не подходит для СИ выше 9 (10 тоже подходит, но смысл переводить из 10 в 10?)? Давайте покажу на примере:
   ```python	
	print(f(13867, 16)) # 36211
   ```

   При попытке перевода программа работает и даже выдаёт какое-то число, но давайте переведём данное число обратно в десятичное. Получится `221713` что уж никак не `13867`. Почему так произошло? Если мы добавим разделитель символов, то мы увидим такой вывод `3|6|2|11` , если заметить, то тут есть число `11`, которое в шестнадцатеричной должно быть `B`, в этом то и проблема. Поэтому для СИ больше 9 используйте следующий вариант. 

4. **Для 2 - 36:**
   Как работает перевод из десятичной в любую другую СИ расписал в прошлом пункте, но проблема что оно не затрагивало СИ выше 9, для этого я создам некий словарь:
   ```python
	A = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ" # Алфавит

	def f(n, b):
		s = ""

		while n != 0:
			s += A[n%b] # Не просто записываем остаток от деления, а получаем строку по  индексу, который является остатком от деления
			n //= b
			
	    return s[::-1]

	print(f(13867, 16)) # 362B
   ```

   В данном примере есть проблема, что если вы забыли или не знаете последовательности латинского алфавита *(фатальная ошибка)*, то просто записать так у вас на экзамене вряд ли получится, поэтому есть уже готовая библиотека `string`, которая позволяет получить латиницу в удобном типе. Использование:
   ```python
   import string
   
   A = "0123456789" + string.ascii_uppercase
   
   print(A) # 0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ
   ```

   Мне лично тяжело запомнить название `ascii_uppercase`, да и название самой библиотеки, поэтому пишу вручную.

5. **Для 37+:**
   Проблема СИ выше 36, что в английском алфавите просто нет символов после Z, и если такая СИ представлена в задании, то перевести в строку не получится, но есть вариант перевести число в массив чисел, которые означают индексы числа в нужной СИ.
   ```python
	def f(n, b):
		R = [] # Массив для всех индексов чисел
		
	    while n != 0:
	        R.append(n%b) # Добавляем индекс в результат
	        n //= b

    return R[::-1] # Переворачиваем массив

	print(f(13867, 48)) # [6, 0, 43]
   ```

   В итоге получаем массив из индексов, которые если вам угодно можно заменить на любы числа и получить строку, но обычным `int()` его преобразить уже будет нельзя. 
## Из СИ в десятичную

1. **Для 2 - 36:**
   Для такого перевода существует функция `int(str, int)`, где первый аргумент это строка числа в СИ, а второй эта самая СИ. Использование:
   ```python
   print(int("10201", 3)) # 100
   print(int("1A3", 14)) # 339
   print(int("COCH", 30)) # 345977
   ```
   
2. **Для 37+:**
   Проблема СИ выше 36, что в английском алфавите просто нет символов после Z, и если такая СИ представлена в задании, то перевести в десятичную будет намного сложнее. Но я буду переводить массив индексов в нужную СИ с помощью функции. Снова теория: Чтобы перевести из любой СИ нужно сложить все цифры числа умноженные на степень счисления в степени индекса числа *(индекс конкретной цифры начиная с 0 справа-налево)*
   ![600](perevod_iz_si_v_dec.png)

   Таким образом напишем нашу функцию перевода:
   ```python
	def f(m, b): #m - массив индексов; b - система счисления
		r = 0 # Перменная результата
		l = len(m) # Длинна массива

		for i in range(l): # Проходимся по длинне всего массива
			r += m[i] * b ** (l - i - 1) # m[i] - цифра; (l - i - 1) - индекс, инвертированный id в массиве и -1, потому что индексы начинается с 0
			
	    return r

	print(f([6, 0, 43], 48)) # 13867
   ```

   Такой вариант вряд ли будет необходим на ЕГЭ, но для понимания логики сделал эту функцию.
