## Тип 1 (От числа до числа)

### Задание 
У исполнителя Удвоитель две команды, которым присвоены номера.

1.  **Прибавь 1.**
2.  **Умножь на 2.**

Первая из них увеличивает число на экране на 1, вторая удваивает его. Программа для Удвоителя  — это последовательность команд. Сколько есть программ, которые число 2 преобразуют в число 22?

### Решение
1. Создаём рекурсивную функцию для перебора `f(x, y)`. Создаём выход функции при `x >= y`, который будет возвращать `x == y` *(при x > y программа выведет 0, результат того что этот путь не сможет дойти до нужного числа, в ином случае x == y  результатом будет 1 путь успешен)* и точку результата, где совместим всевозможные пути ветвления
    ```python
    def f(x, y): # x - с какого числа идём; y - результат
        if x >= y: return x == y # Выход рекурсии
        
        return f(x + 1, y) + f(x * 2, y) # Все пути. y мы сохраняем, потому что результат везде одинаковый
    ```
2. Выводим результат в зависимости от условия
	```python
	def f(x, y)
	    ...
	    
	print(f(2, 22)) # От числа 2 до числа 22
    ```

В ответе получаем `37`!
   
   ### Полный код
```python
def f(x, y): # x - с какого числа идём; y - результат
    if x >= y: return x == y # Выход рекурсии
    
    return f(x + 1, y) + f(x * 2, y) # Все пути. y мы сохраняем, потому что результат везде одинаковый

print(f(2, 22)) # От числа 2 до числа 22
```

## Тип 2 (От числа до числа с числами в последовательности)

### Задание 
Исполнитель преобразует число на экране. У исполнителя есть три команды, которым присвоены номера.

1.  **Прибавить 1.**
2.  **Умножить на 3.**
3.  **Прибавить 2.**

Сколько существует программ, для которых при исходном числе 3 результатом является число 14 и при этом траектория вычислений содержит число 9?
Траектория вычислений программы  — это последовательность результатов выполнения всех команд программы. Например, для программы 132 при исходном числе 7 траектория будет состоять из чисел 8, 10, 30.

### Решение
1. Создаём рекурсивную функцию для перебора `f(x, y)`. Создаём выход функции при `x >= y`, который будет возвращать `x == y` *(при x > y программа выведет 0, результат того что этот путь не сможет дойти до нужного числа, в ином случае x == y  результатом будет 1 путь успешен)* и точку результата, где совместим всевозможные пути ветвления
    ```python
    def f(x, y): # x - с какого числа идём; y - результат
        if x >= y: return x == y # Выход рекурсии
        
        return f(x + 1, y) + f(x * 3, y) + f(x + 2, y) # Все пути. y мы сохраняем, потому что результат везде одинаковый
    ```
2. Выводим результат в зависимости от условия
	```python
	def f(x, y)
	    ...
	    
	print(f(3, 9) * f(9, 14)) # У нас должно входить число 9, поэтому премножаем результаты от 3 до 9 и от 9 до 14
    ```

В ответе получаем `112`!
   
   ### Полный код
```python
def f(x, y): # x - с какого числа идём; y - результат
    if x >= y: return x == y # Выход рекурсии
    
    return f(x + 1, y) + f(x * 2, y) # Все пути. y мы сохраняем, потому что результат везде одинаковый

print(f(2, 22)) # От числа 2 до числа 22
```

## Тип 3 (От числа до числа с исключением чисел в последовательности)

### Задание 
Исполнитель преобразует число на экране.
У исполнителя есть две команды, которые обозначены буквами.

**A.  Вычти 2**
**B.  Если число кратно 3, Раздели на 3, Иначе Вычти 4**

Программа для исполнителя  — это последовательность команд.
Траектория вычислений программы  — это последовательность результатов выполнения всех команд программы. _Например_, для программы **BAB** при исходном числе 99 траектория будет состоять из чисел 33, 31, 27.
Сколько существует программ, которые преобразуют исходное число 38 в число 6 и при этом траектория вычислений не содержит числа 10?

### Решение
1. Создаём рекурсивную функцию для перебора `f(x, y)`. Создаём выходы функции при `x <= y`, который будет возвращать `x == y` *(при x < y программа выведет 0, результат того что этот путь не сможет дойти до нужного числа, в ином случае x == y  результатом будет 1 путь успешен)* и при `x == 10` и точку результатов, где совместим всевозможные пути ветвления
    ```python
    def f(x, y): # x - с какого числа идём; y - результат
        if x == 10: return 0 # Сразу обрубаем, если в последовательности есть число 10
    
        if x <= y: return x == y # Выход рекурсии
        
        if x % 3 == 0: return f(x - 2, y) + f(x // 3, y) # Если x кратно 3, то делим на 3
        
        return f(x - 2, y) + f(x - 4, y) # Иначе вычитаем 4
    ```
2. Выводим результат в зависимости от условия
	```python
	def f(x, y)
	    ...
	    
	print(f(38, 6)) # У нас должно входить число 9, поэтому премножаем результаты от 3 до 9 и от 9 до 14
    ```

В ответе получаем `48`!
   
   ### Полный код
```python
def f(x, y): # x - с какого числа идём; y - результат
    if x == 10: return 0 # Сразу обрубаем, если в последовательности есть число 10
    
    if x <= y: return x == y # Выход рекурсии

    if x % 3 == 0: return f(x - 2, y) + f(x // 3, y) # Если x кратно 3, то делим на 3
    
    return f(x - 2, y) + f(x - 4, y) # Иначе вычитаем 4

print(f(38, 6)) # От 38 до 6
```

## Тип 4 (От числа до числа с исключением нескольких команд или нескольких чисел в последовательности)
У этого типа есть 2 подтипа с исключением команд и нескольких чисел, но я разберу только с командами, по идее это одно и тоже

### Задание 
Исполнитель Калькулятор преобразует число, записанное на экране. У исполнителя есть три команды, которым присвоены номера:

**1.  Прибавь 1**
**2.  Прибавь 2**
**3.  Умножь на 2**

Первая команда увеличивает число на экране на 1, вторая увеличивает его на 2, третья  — умножает на 2. Программа для исполнителя  — это последовательность команд. Сколько существует программ, которые преобразуют исходное число  2  в число  22 и при этом не содержат двух команд «Прибавить 2» подряд?

### Решение
1. Создаём рекурсивную функцию для перебора `f(x, y)`. Создаём выход функции при `x >= y`, который будет возвращать `x == y` *(при x > y программа выведет 0, результат того что этот путь не сможет дойти до нужного числа, в ином случае x == y  результатом будет 1 путь успешен)* и точку результатов, где совместим всевозможные пути ветвления
    ```python
    def f(x, y, c2): # x - с какого числа идём; y - результат; c2 - прошлая команда была вторая?
        if x >= y: return x == y # Выход рекурсии
        
        if c2: return f(x + 1, y, False) + f(x * 2, y, False) # Просто исключаем вторую команду
        
        return f(x + 1, y, False) + f(x + 2, y, True) + f(x * 2, y, False) # Просто все варианты
    ```
2. Выводим результат в зависимости от условия
	```python
	def f(x, y, c2)
	    ...
	    
	print(f(2, 22, False)) # От 2 до 22, первая команда не может быть 2-ой, поэтому False 
    ```

В ответе получаем `4953`!
   
   ### Полный код
```python
def f(x, y, c2): # x - с какого числа идём; y - результат; c2 - прошлая команда была вторая?
    if x >= y: return x == y # Выход рекурсии

    if c2: return f(x + 1, y, False) + f(x * 2, y, False) # Просто исключаем вторую команду

    return f(x + 1, y, False) + f(x + 2, y, True) + f(x * 2, y, False) # Просто все варианты

print(f(2, 22, False)) # От 2 до 22, первая команда не может быть 2-ой, поэтому False
```
