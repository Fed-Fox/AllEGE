## Тип 1

### Задание
Значение арифметического выражения 125 + 25³+ 5⁹ записали в системе счисления с основанием 5. Сколько значащих нулей содержит эта запись?

### Решение
1. Вычисляем значение нашего выражения и записываем в отдельную переменную
  ```python
  n = 125 + 25 ** 3 + 5 ** 9
  ```

2. Создаем или используем готовую функцию для перевода в нужную для нас СС, в нашем случае это будет самописная функция *([подробнее...](Вспомогательные%20моменты.md#Переводы%20СИ))*. И переведём наше число.
  ```python
  n = ...
  
  def f(n, b):
  	  s = ""
  	  	
  	  while n != 0:
  	  	  s += str(n%b)
  	  	  n //= b
  	     
  	  return s[::-1] 
  	
  r = f(n, 5) # n - наше число; 5 - основание в которое переводим
  ```

3. И получаем кол-во нулей благодаря функции count()
  ```python
  r = ...

  print(r.count("0")) # Кол-во символов 0 в строке результата
  ```

В итоге получаем `7` и это правильный ответ!

### Код
```python
n = 125 + 25 ** 3 + 5 ** 9

def f(n, b):
    s = ""

    while n != 0:
        s += str(n%b)
        n //= b

    return s[::-1]
    
r = f(n, 5)

print(r.count("0")) # 7
```

## Тип 2

### Задание
Операнды арифметического выражения записаны в системе счисления с основанием 15:
**123x5₁₅ + 1x233₁₅**
В записи чисел переменной _x_ обозначена неизвестная цифра из алфавита 15-⁠ричной системы счисления. Определите наименьшее значение _x_, при котором значение данного арифметического выражения кратно 14. Для найденного значения _x_ вычислите частное от деления значения арифметического выражения на 14 и укажите его в ответе в десятичной системе счисления. Основание системы счисления в ответе указывать не нужно.

### Решение
1. Создадим цикл для перебора числа `X`, которое будет числом от 0-E. Для этого создадим алфавит и которого мы будем брать символы.
```python
A = "0123456789ABCDE"

for x in range(15):
    ...
```

2. Создаем переменную, в которой у нас будет находится результат выражения. Подставляем значение `X` и переводим в десятичную.
```python
for ...:
	r = int("123" + A[x] + "5", 15) + int("1" + A[x] + "233", 15)
```

3. Проверяем наше условие и выводим при найденном `X`
```python
for ...:
	r = ...
	
	if r % 14 == 0:
		print(x, r // 14)
```

В результате получаем такой вывод
```stacktrace
4 8767 
11 10462
```
Первое число - число `X`, по условию нам нужно самое минимальное `X`, поэтому нам важна первая строчка, Второе число - ответ на задание. Следовательно в задании ответ - `8767`!
### Код
```python
A = "0123456789ABCDE"

for x in range(15):
    r = int("123" + A[x] + "5", 15) + int("1" + A[x] + "233", 15)

    if r % 14 == 0:
        print(x, r // 14)
```

## Тип 3

### Задание
Операнды арифметического выражения записаны в системах счисления с основаниями 9 и 11:
**88x4y₉+ 7x44y₁₁**
В записи чисел переменными _x_ и _y_ обозначены допустимые в данных системах счисления неизвестные цифры. Определите значения _x_ и _y_, при которых значение данного арифметического выражения будет наименьшим и кратно 61. Для найденных значений _x_ и _y_ вычислите частное от деления значения арифметического выражения на 61 и укажите его в ответе в десятичной системе счисления. Основание системы счисления в ответе указывать не нужно.

### Решение
1. Создадим цикл для перебора числа `X` и для числа `Y`, которое будет числом от 0-9 потому, что оба числа могут быть только в минимальной из возможных систем счисления. Например если мы возьмем числа 11-ой СС, то девятеричные числа нам python просто не сможет перевести. В этом случае алфавит не обязателен, но в других задачках с большей СС, желательно его использовать.
```python
for x in range(9):
	for y in range(9):
        ...
```

2. Создаем переменную, в которой у нас будет находится результат выражения. Подставляем значение `X` и `Y` и переводим в десятичную.
```python
for ...:
	for ...:
		r = int("88" + str(x) + "4" + str(y), 9) + int("7" + str(x) + "44" + str(y), 11)
```

3. Проверяем наше условие и выводим при найденном `X` и `Y`
```python
for ...:
	for ...:
		r = ...
	
		if r % 61 == 0:
			print(r, r // 61)
```

В результате получаем такой вывод
```stacktrace
165615 2715
```
Это единственный вывод, но если бы их было больше, то мы бы брали по самому минимальному - первое число. В итоге ответом будет второе число - `2715`!

### Код

```python
for x in range(9):
	for y in range(9):
		r = int("88" + str(x) + "4" + str(y), 9) + int("7" + str(x) + "44" + str(y), 11)
		
		if r % 61 == 0:
			print(r, r // 61)
```
