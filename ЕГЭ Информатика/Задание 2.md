#ИНФОРМАТИКА
Таблица истинности

## Пример

### Задача
Логическая функция _F_ задаётся выражением **(x ∨ y) → (z ≡ x)**.
Дан частично заполненный фрагмент, содержащий **неповторяющиеся** строки таблицы истинности функции _F_.
Определите, какому столбцу таблицы истинности соответствует каждая из переменных _x_, _y_, _z_.

| Переменная 1 | Переменная 2 | Переменная 3 | Функция |
| :----------: | :----------: | :----------: | :-----: |
|     ???      |     ???      |     ???      |    F    |
|              |      0       |      0       |    0    |
|              |      0       |              |    0    |
В ответе напишите буквы _x_, _y_, _z_ в том порядке, в котором идут соответствующие им столбцы (сначала  — буква, соответствующая первому столбцу; затем  — буква, соответствующая второму столбцу, и т. д.). Буквы в ответе пишите подряд, никаких разделителей между буквами ставить не нужно.
_Пример._ Пусть задано выражение _x → y,_ зависящее от двух переменных _x_ и _y_, и фрагмент таблицы истинности:

| Переменная 1 | Переменная 2 | Функция |
| :----------: | :----------: | :-----: |
|     ???      |     ???      |    F    |
|      0       |      1       |    0    |

Тогда первому столбцу соответствует переменная *y*, а второму столбцу соответствует переменная *x*. В ответе нужно написать: *yx*.

### Решение
1. Для начала поймем какие переменные нам нужны *(x, y, z)*, мы будем перебирать все их вариации (**2³**) и использовать их дальше в функции
	```python
	for x in 0, 1:
		for y in 0, 1:
			for z in 0, 1:
				...
	```
   мы присваиваем переменным значения `0, 1` потому, что в python `bool` значения **(True, False)** могут быть преобразованы в числа `1 и 0` соответственно и так же быть использованы в логических операциях. Вкратце `1 == True`, `0 == False` 

2. Далее создадим переменную для хранения результата функции и перепишем всю функцию на язык python *([подробнее про перевод логических операций](Вспомогательные%20моменты.md#Логические%20операции))*
 ```python
 ... # Циклы
 F = (x or y) <= (z == x)
 ```

3. В переменной `F` у нас теперь содержится `bool` или `int` значение результата функции. Далее мы можем исключить варианты, в которых функция равна `0 (False)` и вывести все переменные
```python
F = ...

if not(F):
	print(x, y, z, F)
```

4. Добавим пару деталей (`print("x y z F")`), чтобы было легче сопоставлять функции. В итоге получаем такой вывод
```Stacktrace
x y z F
0 1 1 False
1 0 0 False
1 1 0 False
```
Получили 3 варианта, в которых функция возвращает `False` 

5. Подбираем варианты к получившиеся таблице. Вариант, в котором у нас есть 2 нуля, только один (`1 0 0 False`). Соотнесём и получим что в этом варианте единственная единица стоит у `x`

| Переменная 1 | Переменная 2 | Переменная 3 | Функция |
| :----------: | :----------: | :----------: | :-----: |
|    **x**     |     ???      |     ???      |    F    |
|    **1**     |      0       |      0       |    0    |
|              |      0       |              |    0    |
Далее вариант, в котором `x = 1`, и есть ещё одна единица.  Это вариант `1 1 0 False`, в нем исключим единицу принадлежащую `x` и получим что вторая единица соответствует `y`. 

| Переменная 1 | Переменная 2 | Переменная 3 | Функция |
| :----------: | :----------: | :----------: | :-----: |
|      x       |      z       |      y       |    F    |
|      1       |      0       |      0       |    0    |
|      1       |      0       |      1       |    0    |
Оставшиеся переменная следовательно будет `z` 

**Ответ:** `xzy`

### Итоговый код
```python
print("x y z F")

for x in 0, 1:
    for y in 0, 1:
        for z in 0, 1:
            F = (x or y) <= (z == x)

            if not F:
                print(x, y, z, F)
    
"""
	Вывод
	
	x y z F
	0 1 1 False
	1 0 0 False
	1 1 0 False
"""
```

## Упрощение
При написании циклов есть пару вещей, которых можно упростить или переделать.

- Ускорение написания циклов. Варианты в цикле можно положить в определённую переменную:
  ```python
  t = 0, 1
  
  for x in t:
    for y in t:
        for z in t:
  ```
  - Есть альтернативный способ перебора можно сделать библиотекой `itertools`
  ```python
  from itertools import *
  
  for v in product([0, 1], repeat = 3): # repeat - кол-во переменных
	  x, y, z = map(int, v)
	  
	  ...
  ```
  Эта [библиотека](Python%20фишки.md#Библиотека%20itertools) позволяет перебрать все варианты переменных одним циклом. Удобно если не забыть.
