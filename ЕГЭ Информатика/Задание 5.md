#ИНФОРМАТИКА
В задании придётся перебрать числа, преобразовать каждое из них (по большей части перевести в другую систему счисления) и найти максимальное/минимальное подходящее.

---
## Пример

### Задание
На вход алгоритма подаётся натуральное число _N_. Алгоритм строит по нему новое число _R_ следующим образом.

1.  Строится двоичная запись числа _N_.
2.  К этой записи дописываются справа ещё два разряда по следующему правилу:
	а)  складываются все цифры двоичной записи, и остаток от деления суммы на 2 дописывается в конец числа (справа). Например, запись `11100` преобразуется в запись `111001`;
	б)  над этой записью производятся те же действия  — справа дописывается остаток от деления суммы цифр на 2.
	
Полученная таким образом запись (в ней на два разряда больше, чем в записи исходного числа _N_) является двоичной записью искомого числа _R_.
Укажите **минимальное** число _R_, которое превышает 43 и может являться результатом работы алгоритма. В ответе это число запишите в десятичной системе.

### Решение

1. Для начала я смотрю на то надо найти максимальное или минимальное число, от этого зависит то от какого до какого числа мы будем перебирать. Если найти максимальное `range(1000)[::-1]`, если минимальное `range(1000)`. Число `1000` почти максимально случайное, так можете использовать и `50` и `1000000`, но обычно ответ находится в диапазоне от `0-1000`. Далее делаем цикл, в котором будем перебирать все числа:
   ```python
	 for n in range(1000):
		 ...
   ```

2. Для перевода чисел нам нужно будет использовать какую-то функцию для перевода десятичного числа в двоичное *([подробнее о переводах](Вспомогательные%20моменты.md#Переводы%20СИ))*. Для перевода будем использовать простую функцию `bin(x)`. Допишем...
    ```python
	 for n in range(1000):
		 r = bin(n)[2:]
	 
		 ...
    ```

3. Далее проводим операцию над числом по условию:
   a) Для получения суммы всех цифр в двоичной записи можно просто получить по количеству единиц в записи `r.count("1")`
   б) Буквально то же что и а)
    ```python
	for n in range(1000):
		r = bin(n)[2:]
	
		r = r + str(r.count("1") % 2) # Пункт А
	
		r = r + str(r.count("1") % 2) # Пункт Б
	
		...
    ```

4. Переводим в десятичное, проверяем число и если оно подходит выводим его
    ```python
	for n in range(1000):
		r = bin(n)[2:]
		
		r = r + str(r.count("1") % 2)
		
		r = r + str(r.count("1") % 2)
		
		R = int(r, 2) # Перевод в десятичную СИ
		
		if R > 43: # Проверяем что R больше 43
			print(R) # Выводим число
			break # Завершаем весь цикл, чтобы не перебирать лишние числа (опционально)
    ```

`break` - моя причина проверки максимальное или минимальное число надой найти, в `for` в `range(1000)` будут находится все числа от `0 - 1000` и если программа завершится, то мы получим минимальное число. 

В итоге получаем `46` - ПРАВИЛЬНЫЙ ОТВЕТ!

### Итоговый код
```python
for n in range(1000): # Проходимся по числам от 0 - 1000
	r = bin(n)[2:] # Перводим наше число в двоичное
	
	r = r + str(r.count("1") % 2) # Выполняем пункт А
	
	r = r + str(r.count("1") % 2) # Выполняем пункт Б
	
	R = int(r, 2) # Превращаем в десятичное число
	
	if R > 43: # Проверяем что R больше 43
		print(R) # Выводим число (46)
		break # Завершаем весь цикл, чтобы не перебирать лишние числа (опционально)
```
