#ИНФОРМАТИКА
Обработки числовой последовательности

В задании дается файл, в котором находятся числа в некотором диапазоне.

---

## Пример

### Задание
В файле содержится последовательность целых чисел. Элементы последовательности могут принимать целые значения от `−10 000` до `10 000` включительно. Определите и запишите в ответе сначала **количество пар элементов последовательности, в которых хотя бы одно число делится на 3, затем максимальную из сумм элементов таких пар**. В данной задаче под парой подразумевается два идущих подряд элемента последовательности. Например, для последовательности из пяти элементов: 6; 2; 9; –3; 6  — ответ 4 11.

### Содержимое файла
- -67
- -694
- 835
- 786
- -457
- 495
- -699
- -592
- -405
- ...

### Решение

1. Для начала читаем файл и записываем в массив:
```python
N = list(map(int, open("Название файла")))

или

N = [int(x) for x in open("Название файла")]
```

2. Далее надо будет разделить по парам наши числа:
```python
for numbs in list(zip(N, N[1:])): # Используем list(), потому что в нашем случае его легче обрабатывать. Этот метод более чем двумя парами не работает

или

for i in range(len(N) - 1):
```

3. В нашем случае нужно получить число пар, в которых хотя бы одно число кратно 3-ём:
```python
# Если числа списком
if any(x % 3 == 0 for x in numbs):

# Если числа отдельно
if n1 % 3 == 0 or n2 % 3 == 0:
```

4.  Складываем через простой counter *(или же используем метод из следующего пункта)*
```python
c = 0

...

for numbs in ...:
	if ...:
		c += 1
		
print(c)
```

5. Далее нужно получить максимальную из сумм таких чисел.
```python
# Через массив сумм
A = []

...

for numbs in ...:
	if ...:
		A.append(sum(numbs))

print(len(A)) # Можно и вывести кол-во пар вместо использования counter'а
		
print(max(A))

# Через максимальное число и проверку его

maxsum = -10000

...

for numbs in ...:
	if ...:
		maxsum = max(maxsum, sum(numbs))
		
		или
		
		summ = sum(numbs)
		
		if (maxsum < summ):
			maxsum = summ
		
print(maxsum)
```

В итоге нам выведет число пар и их максимальную сумму.

### Итоговый код

```python
N = list(map(int, open("17.txt"))) # Читаем файл и парсим

A = [] # Создаем список для хранения сумм пар

for numbs in list(zip(N, N[1:])): # Преобразем данные с файла в массив пар
    if any(x % 3 == 0 for x in numbs): # Проверяем условие
        A.append(sum(numbs)) # Добавляем сумму в массив

print(len(A), max(A)) # Выводим кол-во пар и максимальную сумму у этих пар соответственно
```


## Сложности

### "Пары" из трёх и более чисел
При этом способе уже не получится использовать [zip](Функции.md#ZIP), и придётся или создавать массив [срезы](Python%20фишки.md#Срезы) или перебирать поэлементно каждый элемент пары. Рекомендую в любом случае делать массивами, потому что их легче обрабатывать. 

Пример получение пары
```python
N = ...

...

for i in range(len(N) - 2): # Убираем индексы, чтобы не было ошибки index out of range
	numbs = N[i:i + 3] # Срез массива от i до i + 2
```

Так в `numbs` мы получим всю пару из трёх чисел.
