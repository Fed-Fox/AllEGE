# Задание 1 ЕГЭ

## Алгоритм решения не симметричных графов:

1. Обозначить степени вершин в графе и смежной матрице
2. Найти уникальную точку, из которой з выходит отличное от всех количество дорог. 
3. Изучить уникальные степени вершин у соседей.
4. Соотнести степени определённой вершины в графике со смежной матрицей.

## Алгоритм решения симметричных графов:

1. Обозначить степени вершин.
2. Найти уникальную точку.
3. Предположить положение неуникальных степеней в таблице. 
4. Опираясь на связи попробовать определить города.
5. При неверном предположении повторить пункты 3 и 4.
